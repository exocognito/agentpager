## Left out, and why

From Atomic:
- Commit to main with no pull requests: see above.
- XState as the required machine library, vendored library source, Alchemy state rules: specific to its stack.
- Its writing practices: AGENTS.md points to the project's own.

From the Blueprint process:
- The cleanroom run with a builder and reviewer, recipes, the driver, test profiles, approved design snapshots: AgentPager's recipe is retired with v2, and the work runs as worktrees and pull requests.
- Pre-pin formal verification (TLA+ models and deductive closure checks): never run here. Add it back for one hard problem if Sam asks.
- Typed design relations (`depicts`, `checks`, `enforces`) and `serves` links on every promise: the id check and the views do that job with less to maintain.
- Strategy, promises and design as timeless, with no milestone names (law rule 9). `Since <milestone>` breaks that rule on purpose, for the reasons in the table; git history alone would do if Sam answers 2b.
