# Design screens

The real app, drawn from its code: read these to see the design without a Simulator. Generated by `pnpm designs`; don't edit anything here by hand.

Fingerprint: `90e93629ebcf3df8`

The phone is the SwiftUI app (`packages/ios`) in the iPhone 17e Simulator, iOS 27.2, saved at 2x. The web is the front page from the local server in headless Chromium.

## Regenerate

On a Mac with Xcode and the iPhone 17e Simulator, run `pnpm designs` (the last run took about 9 min) and commit this folder. It starts a local server on a free port and stops it after, runs the UI tests (`DesignTests` and the journeys below), renders the front page, and rewrites this folder only once everything has passed. It prints the scratch folder that holds its full log.

The fingerprint is a hash of the 70 files it is drawn from: `packages/ios/AgentPager`, `packages/ios/AgentPagerUITests`, `packages/app/fixtures/briefs`, `packages/app/scripts/briefs.ts`, `packages/cli/src/seal.ts`, `packages/contract`, `packages/app/src/contract.ts`, `packages/app/src/browser.tsx`, `packages/app/scripts/build.mjs`, `packages/app/src/site`, `packages/app/scripts/designs.mjs`. TypeScript unit tests (`*.test.ts`) don't count; the iPhone UI tests do, since they draw the journeys. An untracked file counts only with one of these extensions: .swift, .ts, .tsx, .css, .mjs, .md, .json, .plist, .png, .jpg, .jpeg. The rest of the server (routing, storage, alerts) is left out: it changes often and draws nothing itself, so after a change there that shows on screen, run `pnpm designs` by hand. `pnpm check` fails when the fingerprint no longer matches.

## Journeys: `journeys/`

Interactions as storyboards: each journey's README lists its numbered frames, each with the action that led to it.

| Journey | Frames | What it shows |
| --- | --- | --- |
| [pager](journeys/pager/README.md) | 11 | Make a pager; two agents connect with its number and ask; answer one through the Undo window; the agent confirms; the closed record. |
| [briefs](journeys/briefs/README.md) | 24 | The four example briefs (D1–D4) from a real agent: the Options sheet, images, background pages, picking and sending, asking for changes, and an answered brief. |
| [undo-and-changes](journeys/undo-and-changes/README.md) | 4 | An answer whose sends all fail (Answer Not Confirmed, Retry), Undo inside the window, leaving the app during Undo, and Ask for changes. |
| [off-and-on](journeys/off-and-on/README.md) | 4 | Switch a pager off: its agents are refused and its decision shows Turn on; turn it back on and answer. |
| [delete](journeys/delete/README.md) | 3 | Delete a pager from its detail screen: confirm, and it is gone from the phone. |
