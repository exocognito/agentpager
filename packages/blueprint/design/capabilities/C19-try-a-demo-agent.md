## Behaviors

1. agentpager.me offers a demo. Like a real agent, it shows a link, a QR code and a three-emoji code (C20, C21).
2. After pairing, the demo agent asks one sample decision, acknowledges the answer with its next steps, and finishes, which ends the pager.
3. App Review can complete the demo from the review notes alone.
