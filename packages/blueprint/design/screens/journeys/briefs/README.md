# Journey: briefs

The four example briefs (D1–D4) from a real agent: the Options sheet, images, background pages, picking and sending, asking for changes, and an answered brief.

From `BriefTests/testBriefs` in `packages/ios/AgentPagerUITests`, against a local server, the test playing the agent over the HTTP API. Each frame is the screen after the action written above it. Generated by `pnpm designs`: don't edit it by hand.
