## Horizons

MAPP, MPAGERS and MCOMMAND have shipped. Next, AgentPager gets ready for the first owners beyond Sam ([DEC-2026-10-31-next-roadmap](../records/decisions/DEC-2026-10-31-next-roadmap.md)). On 5 Nov Sam set this order, one milestone at a time ([M4 HOUSE](../../../blueprint/milestones/M4-house.md)).

M4 HOUSE first puts the repo in order: the Blueprint by area, a dev stage, and the id check. MCLIENTS, new, settles which agent apps AgentPager supports; MINSTALL and MSITE wait for it, because both need that list. MOPEN's cleanup waits for MENCRYPT, since both change the same code. MFRIENDS comes last: Sam invites owners once they can install AgentPager, read what it is, inspect its code, and know the service can't read their decisions. Encryption comes before that rollout (STRATEGY, Strategic Design Decisions).

Nothing else is planned. No Android, no answering from the Lock Screen, no Live Activities and no paid tier: nobody has needed them yet. A feature joins the roadmap when owners using AgentPager, Sam included, show they need it. The web app (MCARDS, parked before it closed) stays as history in [parked/](parked/).
